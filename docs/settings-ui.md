# 设置界面

2026-10-14 更新。使用 GPUI Kit 的 TabBar、Collapsible、Input、Switch 和 Checkbox，统一卡片间距与字段对齐，移除长篇常驻说明。

| 页面 | 组织方式 |
| --- | --- |
| 界面 | 主题、正文排版、折叠的代码/终端字体、预览；字体支持搜索已安装字体 |
| 记忆 | 记忆库、设置、任务三个页签；预算和存储默认收起 |
| 人格 | 编辑、预览两个页签；保存/重新加载置顶，文件路径收起 |
| Skills | 已安装列表在前；详情、资源目录、导入、诊断按需展开 |
| MCP | 服务列表在前；连接详情、添加、导入、JSON 配置按需展开 |
| 其它提供商 | 网页搜索启用、Tavily/Exa/Serper 各自独立的密钥/环境变量/地址及草稿、公共超时；搜索使用选中的一家，保存/恢复包含三家配置 |
| 关于 | 品牌与版本、链接、更新 |

提供商表单保持原有结构。配置页的保存/恢复固定在底部；资源管理和人格沿用各自的保存入口。导入列表使用勾选框，启停使用开关。

正文、代码和终端字体使用可搜索下拉框，从平台字体系统获取已安装字体。保留现有配置值，并提供「手动输入…」兜底；选择字体写入设置草稿，沿用预览、保存与恢复流程。

## 记忆与证据

world/experience 是抽取的事实，observation 是基于事实整理的记忆；一条事实也能产生内容相同的 observation。两层同时保存用于追溯，默认列表只展示 observation 与未被存续 observation 覆盖的事实。原始事实页保留证据入口，不删除历史数据。来源在对应卡片内展示，ID 和完整时间收起。

## 验收

代码回归覆盖记忆列表搜索、分页、证据分层及 observation 删除后的事实可见性。GPUI 事件测试覆盖页面绘制、设置折叠展开/收起、三家搜索提供商切换时的草稿隔离、Web / 模型披露配置保存恢复，不代表像素级视觉验收。

真实界面由用户手工验收，启动方式：`cargo run -p hikari`。

- 深浅主题、窗口缩小时的对齐与滚动；底部保存栏可见。
- 折叠区展开/收起；记忆与人格页签切换。
- 字体预览、保存、恢复；MCP/Skill 的启停、导入与管理操作。
- 记忆默认列表无证据层重复；原始事实和来源可查看，搜索/翻页正常。
